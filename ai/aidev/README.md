# AIDEV Index

这个目录保存 Daylily 的 AI 开发约束。

它回答四类问题：

1. AI 怎么接手：见 `start-here.md`。
2. 项目是什么：见 `project-map.md`、`concepts.md`。
3. 架构怎么分层：见 `architecture.md`、`runtime-contracts.md`、`invariants.md`。
4. API 和参数怎么写：见 `api-registry.md`、`conventions.md`。
5. AI 怎么继续开发：见 `workflow.md`、`task-protocol.md`、`extension-playbooks.md`、`roadmap.md`。
6. Epic 和 task 在哪里：见 `../epics/` 和 `../tasks/`。

每次公共 API、模块边界、命令、任务协议变化时，都要同步更新这里。

原则：

> AIDEV 必须足够自包含，让 AI 不需要先读源码也能理解 Daylily 的使用、升级和扩展方式。
